# FitTrack PWA — личный трекер тренировок

Мобильное PWA-приложение на русском языке, адаптированное для iPhone. Работает без аккаунта и хранит данные в `localStorage` браузера на устройстве.

## Возможности

- Три тренировочных дня: A (понедельник), B (среда), C (пятница).
- Отметка каждого подхода, запись веса и повторений, добавление дополнительных подходов.
- Подсказки по технике и целевым мышцам.
- Таймер отдыха на 60, 90 и 120 секунд.
- История тренировок и рабочих весов.
- Запись веса тела и график динамики.
- Экспорт/импорт JSON-резервной копии.
- PWA-манифест и Service Worker для установки и кеширования оболочки.

## Важно

- Приложение не передаёт данные на сервер. Очистка данных сайта/браузера может удалить историю — регулярно экспортируй резервную копию.
- Таймер и уведомление/вибрация могут работать ограниченно, когда Safari свёрнут или экран заблокирован: iOS может приостанавливать фоновые таймеры.
- Для установки PWA и Service Worker нужен HTTPS (кроме `localhost` для разработки).
- Локальная версия не синхронизируется между устройствами.
- Программа тренировок — стартовый шаблон. При истории проблем с позвоночником подбирай нагрузку индивидуально и не выполняй упражнения через боль.

## Быстрый запуск локально на компьютере

В каталоге проекта запусти:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`. Это удобно для проверки на компьютере, но не является способом установки на iPhone, пока сайт не размещён по HTTPS.

## Публикация через GitHub Pages

1. Создай новый репозиторий на GitHub, например `fittrack-pwa`.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, папку `icons` и `README.md`.
3. В репозитории открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохрани.
5. Дождись публикации. GitHub Pages выдаст HTTPS-адрес вида `https://ИМЯ.github.io/fittrack-pwa/`.
6. На iPhone 16 открой этот адрес в Safari → **Поделиться** → **На экран Домой** → **Добавить**.
7. Проверь работу офлайн после первого открытия. Экспортируй резервную копию из раздела «Профиль».

### Обновление после изменений

Загрузи обновлённые файлы в репозиторий. При необходимости увеличь версию `CACHE_NAME` в `sw.js` (например, `fittrack-cache-v2`), чтобы Service Worker скачал новую оболочку.

## Проверка перед использованием

- Начни тренировку, введи вес/повторения, отметь несколько подходов.
- Заверши тренировку и проверь её во вкладке «История».
- Добавь вес тела и проверь вкладку «Прогресс».
- Экспортируй и импортируй резервную копию.
- На iPhone проверь установку и работу при отключённом интернете.

## Структура

- `index.html` — интерфейс приложения.
- `styles.css` — адаптивный тёмный дизайн.
- `app.js` — тренировки, отметки, графики и локальное хранилище.
- `manifest.webmanifest` — настройки PWA.
- `sw.js` — офлайн-кеш оболочки приложения.
- `icons/` — иконки.
